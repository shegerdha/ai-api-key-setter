# Bundled assets

These files are committed in the repository and bundled into the PyInstaller build.

| File                           | Use                       | Source / license                                                                                                      |
| ------------------------------ | ------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `fonts/IRANYekanX-Regular.ttf` | UI Persian font           | IRANYekanX — verify redistribution terms with the font publisher before public release.                               |
| `icons/app-icon.png`           | Application icon (source) | [Flaticon](https://www.flaticon.com/) — free download with attribution; confirm license if distributing commercially. |
| `icons/app-icon.ico`           | Windows exe icon          | Generated from `app-icon.png` during build.                                                                           |
| `icons/chevron-down.svg`       | Combo box arrow           | Project asset (simple SVG).                                                                                           |

If you replace any asset, update this table and keep filenames aligned with `ai-api-key-setter.spec` and `build.ps1`.
